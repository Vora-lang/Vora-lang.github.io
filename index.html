一门动态类型的脚本语言——类 JavaScript 语法，Lua 级的简单性，Wren 式的面向对象。

快速开始

一条命令，即刻运行

跨平台构建，零外部依赖。支持 Windows、Linux、macOS 多架构与原生打包。

# 构建（Windows / Linux / macOS）
PS> .\build.ps1
$ ./build.sh

# 多架构交叉编译 + 打包
$ ./build.sh -a arm64 -c release -p  → .deb / .rpm / .pkg.tar.xz
PS> .\build.ps1 -Architecture arm64 -Config Release -Package  → .msi

# 运行脚本
$ vora hello.va
$ vora --repl

函数与闭包

func add(a, b) { return a + b }

// 闭包直接修改外层变量
func makeCounter() {
    let n = 0
    return func() { n += 1; return n }
}

// 默认参数 + 命名参数
func greet(name, g = "Hello") { ... }
greet(name="Vora", g="Hi")

控制流

for item in [1,2,3] { print(item) }
for i in range(10) { print(i) }

对象与继承

Obj Animal(name) {
    this.name = name
    func speak() { print("...") }
}

Obj Dog : Animal (name, breed) {
    this.breed = breed
    func speak() {
        print("Woof! I'm " + this.name)
    }
}
let d = Dog("Rex", "Husky")

模式匹配

let grade = match score {

func describe(n) {

设计理念

为嵌入而生，为开发者而设计

Vora 不是要替代 Python 或 JavaScript——它是你项目中那个轻量、可靠、零依赖的脚本引擎。

📦 零依赖

纯 C++17 + STL。一个 vora.hpp 单头文件即可嵌入任何 C++ 项目。

⚡ 字节码 VM

基于栈的虚拟机，50+ 条指令。支持快速数值操作码、全局变量驻留、常量折叠。

🧬 原生 OOP

C3 线性化多继承、super 调用、自动 this 绑定。不是 metatable 模拟——是真正的类系统。

📚 8 个标准库模块

math、json、fs、os、datetime、array、string、regex——覆盖日常开发核心场景。

🌍 跨平台

CMake 预设覆盖 Windows (x64/x86/arm64)、Linux (x64/x86/aarch64/armhf)、macOS Universal。

🛡️ 测试完备

328 个 C++ 单元测试（1019 断言）+ 71 个脚本测试 + 56 个示例，全部通过。

项目结构

清晰、模块化、~9,400 行

从词法分析到字节码执行，每个模块职责单一。标准库与核心引擎解耦，按需加载。

Vora/
├── src/
│   ├── lexer/ 词法分析器（~687 行）
│   ├── ast/ AST 节点 + Visitor 接口 + AST Printer（~1,629 行）
│   ├── parser/ Pratt 解析器（~1,200 行）
│   ├── vm/ Compiler + 栈式虚拟机（~3,175 行）
│   ├── runtime/ 值系统 / 作用域 / 可调用对象 / 错误
│   ├── gc/ 标记-清除垃圾回收器
│   ├── lsp/ 语义分析器（符号表、引用、诊断）
│   └── formatter/ AST 源码格式化器（vora fmt）
├── std/ 标准库（8 个模块）
├── examples/ 55 个示例 + main.va 全特性演示
├── tests/ 71 个脚本测试 + 328 个单元测试
├── docs/ 15 篇开发文档（中文）
├── cmake/ 6 个交叉编译工具链
├── build.ps1 / build.sh 跨平台构建脚本
└── CMakePresets.json 20 个预设配置
