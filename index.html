一门语言，
三种灵魂

Vora 是动态类型脚本语言，融合 JavaScript 的熟悉语法、Lua 的轻量级简单性、Wren 的优雅面向对象。

GitHub 快速开始 ↓
~9,400 行 C++17 · 字节码 VM（50+ 指令） · Win / Linux / macOS
hello.va 
// Vora — JavaScript-like syntax, Lua simplicity, Wren-style OOP

Obj Greeter(greeting) {
    this.greeting = greeting
    func say(name) {
        return "${greeting}, ${name}!"
    }
}

let hi = Greeter("Hello")
let names = ["World", "Vora", "你"]

for name in names {
    print(hi.say(name))
}

// → Hello, World!
// → Hello, Vora!
// → Hello, 你!
开始使用

一条命令构建，开箱即用

跨平台一键构建脚本，支持多架构交叉编译与原生打包。

# Windows (PowerShell) — 默认 x64 Debug
PS> .\build.ps1
# Linux / macOS — 默认 x64 debug
$ ./build.sh

# 多架构 + 打包（Release）
PS> .\build.ps1 -Architecture arm64 -Config Release -Package → .msi
$ ./build.sh -a arm64 -c release -p → .deb / .rpm / .pkg.tar.xz

# 运行脚本
$ vora hello.va
$ vora --repl # 交互模式
$ vora hello.va --tokens # 查看 Token 流
$ vora hello.va --ast-printer # 查看 S-expression AST

# 安装（Release 包）
# Windows: .msi 双击安装（自定义目录 + 自动 PATH）
# Linux: sudo dpkg -i vora-*.deb | sudo rpm -i vora-*.rpm
# macOS: tar xzf vora-*.tar.gz -C /usr/local/bin
语法速览

一眼看懂，和写 JS 一样自然

Vora 的语法受到 Lua 和 Wren 的启发，追求极简与可读性。以下是核心语法一览。

类型与变量

let n = 42           // Int (int64)
let f = 3.14         // Float (float64)
let b = true         // Boolean
let s = "hello"      // String (UTF-8)
let a = [1, 2, 3]    // Array
let d = {k: "v"}     // Dict
let nothing = null

// 数字前缀
0xFF 0o77 0b101

函数

func add(a, b) { return a + b }

// Lambda
let double = func(x) { return x * 2 }

// 默认参数 + 闭包
func counter(start = 0) {
    let n = start
    return func() { n += 1; return n }
}

控制流

if (x > 0) { print("+") }
else { print("-") }

while (n > 0) { n -= 1 }
do { n += 1 } while (n < 5)

for item in [1,2,3] { print(item) }
for i in range(10) { print(i) }
for (let i=0; i<5; i+=1) {}

对象与继承

Obj Animal(name) {
    this.name = name
    func speak() { print("...") }
}

Obj Dog : Animal (name, breed) {
    this.breed = breed
    func speak() {
        print("Woof! I'm " + this.name)
    }
}

模式匹配

let grade = match score {
    90..=100 => "A",
    80..=89  => "B",
    70..=79  => "C",
    _        => "F"
}

func describe(n) {
    return match n {
        0 => "zero",
        1 => "one",
        _ => "many"
    }
}

异常处理

try {
    throw "something went wrong"
} catch (e) {
    print("Caught: " + e)
} finally {
    print("Always runs")
}

// 可以 throw 任何值
throw 404
throw {code: 500, msg:"err"}
为什么选择 Vora

嵌入优先，语法现代

Vora 从零开始为嵌入场景设计，同时提供开发者熟悉的现代语法体验。

📦

零依赖

纯 C++17 + STL，无任何外部库依赖。一个 vora.hpp 单头文件即可嵌入你的项目。

⚡

字节码 VM

基于栈的虚拟机，50+ 条指令。支持快速数值操作码、全局变量驻留、常量折叠优化。

🧬

原生 OOP

C3 线性化多继承、super 调用、自动 this 绑定——不是 Lua 的 metatable 模拟，是真正的类系统。

🔧

8 个标准库模块

math、json、fs、os、datetime、array、string、regex——覆盖文件 IO、日期、正则等核心场景。

🌍

跨平台构建

CMake 预设支持 Windows (x64/x86/arm64)、Linux (x64/x86/aarch64/armhf)、macOS Universal 二进制。

🛡️

稳定可靠

328 个 C++ 单元测试（1019 断言）+ 71 个脚本测试 + 56 个示例，100% 通过。20 项 P3 技术债已清零。

项目结构

清晰的模块化架构

~9,400 行 C++17，从词法分析到字节码执行，每个模块职责分明。

Vora/
├── src/
│   ├── lexer/ 词法分析器（~687 行）
│   ├── ast/ AST 节点 + Visitor 接口 + AST Printer（~1,629 行）
│   ├── parser/ Pratt 解析器（~1,200 行）
│   ├── vm/ 字节码 VM：Compiler + 栈式虚拟机（~3,175 行）
│   ├── runtime/ 值系统 / 作用域 / 可调用对象 / 错误（~719 行）
│   ├── gc/ 标记-清除垃圾回收器
│   ├── lsp/ 语义分析器（符号表、引用、诊断）
│   ├── formatter/ AST 源码格式化器（vora fmt）
│   └── common/ 错误报告基础设施
├── std/ 标准库（8 个模块：array, datetime, fs, json, math, os, regex, string）
├── examples/ 55 个示例文件 + main.va 全特性演示
├── tests/ 71 个脚本测试 + 328 个 C++ 单元测试 + CI 矩阵
├── docs/ 15 篇开发文档（中文）
├── cmake/ 交叉编译工具链（6 个）
├── res/ 图标、WiX 安装模板、启动器
├── build.ps1 / build.sh 跨平台构建脚本
├── CMakePresets.json 20 个预设配置
└── CMakeLists.txt
