1. 类型系统

Vora 是动态类型语言，变量在运行时持有任意类型的值。

运行时类型

类型字面量C++ 内部表示说明
Nullnullstd::nullptr_t空值，所有未初始化的默认值
Number42, 3.14doubleIEEE 754 双精度浮点（唯一数值类型）
Booleantrue, falsebool逻辑真/假
String"hello", 'world'std::stringUTF-8 编码，单引号和双引号等价
Array[1, 2, 3]shared_ptr<Array>动态数组，元素可为任意类型
Functionfunc f() {}shared_ptr<Callable>一等公民，可作为值传递
ObjectObj Foo() {}shared_ptr<ObjectInstance>类实例，含属性和方法

数字字面量

Vora 支持多种进制的数字表示：

42 // 十进制 3.14 // 浮点数 0xFF // 十六进制 (255) 0o77 // 八进制 (63) 0b101 // 二进制 (5)

1 / 2 结果为 0.5，与 Python 3 语义一致。没有整数除法。

真值规则

只有 null 和 false 被视为"假"（falsy），其余所有值——包括 0、""、[]——均为"真"（truthy）。

null → falsy false → falsy 0 → truthy "" → truthy [] → truthy

2. 变量与作用域

变量声明

使用 let 关键字声明变量。必须显式声明，不能对未声明变量赋值。

let x = 10
let name = "Vora"
let arr = [1, 2, 3]

类型标注（可选）

声明时可添加 :int 或 :float 标注（当前仅作文档用途，不强制校验）：

let x:int = 42
let y:float = 3.14

赋值

赋值运算符 = 沿词法作用域链向上查找变量并更新其值。如果在当前作用域和所有父作用域中都找不到，则报运行时错误。

let x = 10
x = 20 // 重新赋值
x = x + 1 // x 现在是 21

块作用域

{ } 块创建新的作用域。内层可以遮蔽（shadow）外层变量。

let x = 10
{
    let x = 30 // 遮蔽外层的 x
    print(x) // 30
}
print(x) // 10（外层 x 未受影响）

3. 运算符

运算符优先级表

优先级运算符结合性说明
1=右赋值
1|| or左逻辑或（短路求值）
2&& and左逻辑与（短路求值）
2? :右三元条件运算符
3== !=左相等性比较
4< <= > >=左关系比较
5+ -左加法/减法（+ 同时支持字符串拼接和数组合并）
6* / %左乘法/除法/取模
7**右幂运算
—++ --—自增/自减（前缀和后缀）
—+= -= *= /= %=右复合赋值
—! -右一元：逻辑非 / 算术取反

算术运算符

10 + 3 // 13
10 - 3 // 7
10 * 3 // 30
10 / 3 // 3.333...
10 % 3 // 1
2 ** 8 // 256（右结合：2 ** 3 ** 2 = 2 ** 9 = 512）

字符串拼接

+ 运算符对字符串进行拼接。一方为字符串、另一方非字符串时，非字符串方被自动转为字符串。

"Hello" + " " + "World" // "Hello World"
"The answer is " + 42 // "The answer is 42"

数组操作

[1, 2] + [3, 4] // [1, 2, 3, 4]（合并）
[1, 2] + 99 // [1, 2, 99]（追加）
99 + [1, 2] // [99, 1, 2]（前插）

比较运算符

5 < 10 // true
5 == 5 // true
"a" != "b" // true
null == null // true

逻辑运算符（短路求值）

&& 和 || 执行短路求值，返回实际值而非布尔化结果。这赋予它们类似 Lua 的强大语义：

// 短路求值：右操作数可能不被执行
false && crash() // crash() 永远不会被调用
true || crash() // crash() 永远不会被调用

// 返回实际值
0 || "default" // "default"（0 是 truthy，所以短路返回 0！）
null || "fallback" // "fallback"（null 是 falsy，返回右值）
"hi" && 42 // 42（"hi" 是 truthy，返回右值）
注意：Vora 中 0 是 truthy！这与 C/JavaScript 不同。|| 仅对 null 和 false 触发短路。

三元运算符 ? :

let result = score > 60 ? "pass" : "fail"

// 右结合：a ? b : c ? d : e → a ? b : (c ? d : e)
let grade = score > 90 ? "A" : score > 80 ? "B" : "C"

自增/自减

let x = 5
print(x++) // 5（后缀：先返回，后自增）
print(x) // 6
print(++x) // 7（前缀：先自增，后返回）

复合赋值

let x = 10
x += 5 // x = 15（对应 x = x + 5）
x -= 3 // x = 12
x *= 2 // x = 24
x /= 3 // x = 8
x %= 5 // x = 3

4. 控制流

if / else

if (x > 0) {
    print("positive")
} else if (x < 0) {
    print("negative")
} else {
    print("zero")
}

条件表达式 不需要 加括号 —— if x > 0 { } 同样有效。else if 通过嵌套 IfStmt 实现。

while 循环

let i = 0
while (i < 5) {
    print(i)
    i += 1
}

for-in 循环

支持三种可迭代对象：数组、字符串、range()。

// 遍历数组
for item in [1, 2, 3] {
    print(item)
}

// 遍历字符串（逐字符）
for ch in "Vora" {
    print(ch) // V, o, r, a
}

// 遍历 range
for i in range(5) {
    print(i) // 0, 1, 2, 3, 4
}

每次迭代创建新的作用域，循环变量在迭代结束后不可见。

break / continue

while (true) {
    if (condition) break // 退出循环
    if (skip) continue // 跳过本次迭代
}

5. 函数与闭包

函数声明

func add(a, b) {
    return a + b
}

let result = add(3, 4) // 7

一等公民

函数可以赋值给变量、作为参数传递、作为返回值。

let f = func(x) { return x * 2 }
print(f(5)) // 10

return

函数通过 return 返回值。无 return 语句或 return 无表达式时，函数返回 null。

闭包

Vora 支持完整的词法闭包 —— 内层函数捕获定义时所在作用域的变量：

func makeCounter() {
    let count = 0
    return func() {
        count = count + 1
        return count
    }
}

let c = makeCounter()
print(c()) // 1
print(c()) // 2
print(c()) // 3

每个闭包拥有自己独立的捕获环境（多个实例互不影响）：

let c1 = makeCounter()
let c2 = makeCounter()
print(c1()) // 1
print(c1()) // 2
print(c2()) // 1（独立）

VM 实现：编译器通过 resolveUpvalue() 在编译期确定每个内层引用对应外层哪个局部变量，运行时 VM 维护 openUpvalues 链表以正确共享捕获的变量。这比解释器的 Environment::snapshot() 全量深拷贝更高效。

参数校验

func greet(name) {
    print("Hello " + name)
}
greet("World") // ✅ 1 个参数
greet() // ❌ 参数个数不匹配，抛出错误

变参函数（如 print、range）的 arity 设为 -1，允许任意数量的参数。

6. 对象与继承

Obj 声明

Obj 关键字定义类。构造函数参数列在类名后的括号中。类体内可以设置属性（通过 this）和定义方法。

Obj Person(name, age) {
    this.name = name
    this.age = age

    func greet() {
        print("Hi, I'm " + this.name)
    }
}

let p = Person("Alice", 25)
p.greet() // Hi, I'm Alice
print(p.name) // Alice
p.age = 26 // 属性赋值

单继承

语法：Obj Child : Parent (params) { ... }。构造函数链从根到叶执行，参数按索引从父类构造函数签名中获取。

Obj Animal(name) {
    this.name = name
    func speak() { print("...") }
}

Obj Dog : Animal (name, breed) {
    this.breed = breed
    func speak() {
        print("Woof! I'm " + this.name + " the " + this.breed)
    }
}

Obj Puppy : Dog (name, breed, toy) {
    this.toy = toy
}

let d = Dog("Rex", "Husky")
d.speak() // Woof! I'm Rex the Husky
print(d.name) // Rex（父类构造函数设置的属性）

继承机制

  • 构造函数链：从最远祖先到当前子类依次执行。父类构造函数的参数按索引从子类参数列表的前 N 个获取。
  • 方法查找：当前类 → 父类 → 父类的父类 → ... 沿着继承链向上搜索。
  • 方法覆盖：子类同名方法覆盖父类方法。没有 super 关键字（无法显式调用父类被覆盖的方法）。
  • 多层继承：A → B → C 支持任意深度。
  • this 绑定：方法调用时 this 自动绑定到调用对象。

7. 异常处理

try / catch / finally

支持三种组合形式：try/catch、try/finally、try/catch/finally。

try {
    let x = 1 / 0
} catch (e) {
    print("Error: " + e)
} finally {
    print("Cleanup always runs")
}

finally 块始终执行，无论 try 块正常结束/抛出异常/遇到 return/break/continue。VM 编译器会捕获 try 体内的非局部跳转，在字节码级重放到 finally 块后跳至原目标。

throw

throw 可抛出任意 Vora 值——字符串、数字、对象等：

throw "something went wrong"
throw 42
throw ValidationError("Invalid input")

自定义错误

Obj ValidationError(msg) {
    this.message = msg
    func toString() { return "ValidationError: " + this.message }
}

func checkAge(age) {
    if (age < 0) throw ValidationError("Age cannot be negative")
    if (age > 150) throw ValidationError("Age out of range")
}

try {
    checkAge(-5)
} catch (e) {
    print(e.message) // "Age cannot be negative"
}

catch 变量绑定

  • 捕获到内建运行时错误（如除以零）时，e 绑定为错误消息字符串
  • 捕获到用户 throw 的值时，e 绑定为原值（字符串、对象、数字等）

8. 字符串与插值

字符串字面量

单引号 '...' 和双引号 "..." 完全等价。支持转义序列：\n、\t、\r、\0、\\、\"、\'。未识别转义保留原文不报错。

字符串插值

${...} 在字符串中嵌入 Vora 表达式：

let name = "World"
print("Hello ${name}!") // "Hello World!"

// 多级属性访问
Obj Point(x, y) { this.x = x; this.y = y }
let p = Point(10, 20)
print("Position: (${p.x}, ${p.y})") // "Position: (10, 20)"

// 未定义变量 — 保留原文，不报错
print("Hello ${undefined_var}!") // "Hello ${undefined_var}!"

VM 在编译期解析插值表达式，生成 OP_INTERPOLATE 指令而非运行时扫描——效率更高。

字符串索引

let s = "Vora"
print(s[0]) // "V"
print(s[3]) // "a"

9. 数组

// 创建
let arr = [1, 2, 3]
let mixed = [42, "hello", true, null]

// 索引（从 0 开始）
print(arr[0]) // 1
print(arr[1]) // 2

// 索引赋值
arr[0] = 99

// 越界访问 — 抛出 RuntimeError
// arr[999] → 运行时错误

// 合并
let c = [1, 2] + [3, 4] // [1, 2, 3, 4]

// 追加
let d = [1, 2] + 99 // [1, 2, 99]
let e = 99 + [1, 2] // [99, 1, 2]

// 嵌套数组
let matrix = [[1, 2], [3, 4]]
print(matrix[0][1]) // 2

当前限制：数组没有 .length 属性、.push()、.pop() 等方法 —— 这些在 P0 路线图中优先实现。

10. 注释

// 行注释

/* 块注释 */

/* 外层
   /* 内层 */
   仍在注释中 */

块注释支持嵌套——使用 depth 计数器跟踪嵌套级别，正确匹配 /* 和 */ 对。

语句分隔符

分号 ; 可选——Vora 不强制要求分号。块内语句通过换行自然分隔。
